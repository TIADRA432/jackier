# Identité visuelle — Le Jacquier

Ce dossier est versionné avec le dépôt. Il contient les éléments de référence
utilisés comme repli du site avant qu'un administrateur sélectionne ses propres
médias dans **Paramètres → Identité visuelle**.

## Fichiers

- `le-jacquier-logo.svg` — logo horizontal, utilisé par défaut dans l’en-tête.
- `le-jacquier-mark.svg` — monogramme carré pour les petits formats.

Les SVG de ce dossier sont des créations internes simples. Les nouvelles images
photographiques passent par la médiathèque ; les fichiers de ce dossier restent
la source de secours versionnée dans Git.
